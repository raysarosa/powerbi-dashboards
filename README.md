# 📊 Power BI Dashboard – Análise de Usuários, Compras e Atendimento

Este dashboard foi desenvolvido como parte prática do curso de Power BI que estou a realizar. O objetivo do projeto é aplicar conceitos de modelagem de dados, transformação via Power Query (M) e criação de medidas em DAX, usando dados reais simulados de usuários, vendas e atendimento ao cliente.

---

## 💡 Principais Análises

### 🛍️ Visão de Compras
- Total de vendas em 2024
- Valor médio de compra mensal
- Volume de compras ao longo do ano
- Produtos mais vendidos (Mentoria, Ebook, Curso)
- Distribuição de formas de pagamento (Cartão de Crédito vs. Boleto)

### 👤 Perfil dos Usuários
- Quantidade total de usuários
- Renda média
- Idade média
- Distribuição geográfica por estado

### 🎧 Visão de Atendimento
- Quantidade de tickets por tipo de problema
- Tempo médio de atendimento por mês
- Média de NPS por atendente
- Status dos atendimentos (Aberto, Em progresso, Resolvido)

---

## 🛠️ Tecnologias Utilizadas
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query (M)
- Integração com Google Sheets como fonte externa
